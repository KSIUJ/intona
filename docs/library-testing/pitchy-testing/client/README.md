## PITCHY TEST

This website was built to only test capabilities of pitchy library. Test was recorded and can be viewed [here](intona/docs/library-testing/client/pitchy-test.webm). Sample used as testing material was sounds generated by tuner from D4-H4. 
Test results:
sound | real frequency | detected avg frequency |
|-----|-----------|--------------|
H | 493,88 Hz | ~493,80 Hz |
B | 466,16 Hz | ~466,20 Hz |
A | 440 Hz | ~439,97 Hz |
G# | 415,30 Hz | ~415,20 Hz |
G | 392 Hz | ~392,05 Hz |
Real frequencies were calculated using [website](https://www.cmuse.org/note-to-frequency-calculator/)
This test provided following insights:
- accuracy in detection was very good (~99,98%)
- in the video very strong fluctuations can be observed while testing last note, that was because of changing the distance between sound source and microphone -> that can be an issue while dealing with user input that very often is not so ideal as clear sound without noise in the background
- it can be very hard to test accuracy on real songs because there isn't much reference material for all frequencies in the song
- pitchy developers deliver playground for testing the best configuration for pitch detection and it can be found [here](https://ianjohnson.dev/pitchy/playground.html) however it needs further investigation and planning how exactly it can be tested and used in the context of our application
